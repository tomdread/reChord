Trigger Keys (MIDI Note Inputs) Trigger Key Function Output NOTE_FULL_CHORD_TRIGGER (58) Play full current chord chord NOTE_FULL_STRING_TRIGGER (73) Play full current chord to string output string STRING_TRIGGER_NOTES (76–84) Play individual notes from chord (index-based) string BASS_TRIGGER_NOTES (75–82) Play root or lower voices from chord bass NOTE_CHORD_TRIGGER_TOGGLE (48) Toggle pad-trigger mode on/off Logic flag These are expressive MIDI note triggers that let a single chord be remapped across instruments—like a guitarist plucking individual notes while a keyboardist stabs full chords. ⸻ 🧬 2. Transpose Keys (MIDI Notes 60–71 = C3–B3) Each press changes transposeOffset, a semitone shift applied to all chord notes: • C3 (MIDI 60) = 0 • C#3 (MIDI 61) = +1 • D3 (MIDI 62) = +2 • F3 = +5, etc. This allows key modulation on the fly ⸻ ⬆️ 3. Octave Shift Keys Note Affects Which Output Behavior NOTE_CHORD_OCTAVE_UP (59) chord +1 fullChordOctaveOffset NOTE_CHORD_OCTAVE_DOWN (57) chord –1 fullChordOctaveOffset NOTE_STRING_OCTAVE_UP (74) string +1 stringOctaveOffset NOTE_STRING_OCTAVE_DOWN (72) string –1 stringOctaveOffset Pressing UP + DOWN within a short window resets to 0. ⸻ 🔄 How the Current Chord Is Transformed Before Output Every triggered chord (from pad or key) is run through this real-time transformation pipeline before it hits the output. ⸻ 🧪 Step-by-Step Transformation Pipeline let baseChord = Chords.string; 1. Transpose baseChord.map(n => n + transposeOffset); 2. Octave Offset • + fullChordOctaveOffset * 12 → if output is "chord" • + stringOctaveOffset * 12 → if output is "string" note + transposeOffset + (octaveOffset * 12); 3. Inversion for Full Chord output invertedChord = invertChord(notes, currentInversion); Reorders notes, rotating root/third/fifth upward like: C E G → E G C → G C E ... 4. Velocity Tilt for Full Chord output tiltedNotes = applyVelocityTilt(invertedChord, ccValue); • Higher notes = louder or softer • Simulates expressive voicing • Centered around tiltPivot 5. Send Notes to Output send([NOTE_ON, pitch, velocity], outputType); Sent to: • "chord" → main harmony bus • "string" → arpeggiated or legato layer • "bass" → low-end • "main" → raw passthrough (e.g., in record mode or stop mode) ⸻ 🎼 Output Mapping Summary Output Type Triggered By Note Transformations chord Full chord trigger / pads Inversion → Tilt → Transpose → Octave string Full string trigger / string notes → Transpose → Octave bass Bass trigger notes Select note → Transpose → -1 Octave main Live input (record mode) No transformation — passthrough ⸻ 🧠 Why This Design Is Smart ✅ Modular transformation stages Each step (transpose, invert, tilt, octave) is isolated and chainable. ✅ Live performance control Transpose and octave are mapped to keys.
